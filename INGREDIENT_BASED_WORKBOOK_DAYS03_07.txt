================================================================================
       GOOGLE FLOW: INGREDIENT-BASED UNIFIED GENERATION WORKBOOK
       STRICT 1-OUTFIT 3-SLIDE EDITORIAL CONSISTENCY (DAYS 3 TO 7)
================================================================================

WORKFLOW INSTRUCTIONS:
This workflow uses Google Flow's Multi-Ingredient Composer:
1. FIRST, generate the Dress & Background reference stills for each day.
2. THEN, drag/attach the Character Asset + Dress Image + Background Image
   as ingredients into the Flow prompt composer.
3. Generate the 3 carousel slides for that day.
   Because all 3 slides use the SAME dress image and the SAME background image
   as reference ingredients, 100% of the attire, fabric texture, styling,
   and accessories remain perfectly consistent across the post.
